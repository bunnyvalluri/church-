# KCM Multilingual Internationalization (i18n) Guide

## 1. Supported Locales & Dictionary Parity
The platform natively supports 3 languages across all UI surfaces:
1. **English (`en`)** — Canonical Reference (2,286 keys)
2. **Telugu (`te`)** — Regional Primary (2,286 keys / 100% key parity)
3. **Hindi (`hi`)** — National Language (2,286 keys / 100% key parity)

## 2. Automated Sync Verification
CI/CD pipeline runs `npm run i18n:check -w frontend` to ensure zero missing or untranslated keys before production deployment.
